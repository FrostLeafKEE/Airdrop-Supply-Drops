# Independent appearance examples

Requires Airdrop: Supply Drops 1.0.14+. Enable this pack and set a supply type's `appearance` to `example_airdrops:military` or `example_airdrops:medical`. This pack does not add loot or supply types. It leaves the default mineral/food crates and shared parachute unchanged. The models are simple integration demonstrations, not the partner collaboration assets. See `MODEL-APPEARANCES.md` for the full contract.
